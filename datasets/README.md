# Datasets Folder

This folder organizes outputs by maturity level.

- 01_raw: raw collected data
- 02_clean: cleaned data
- 03_docs_v2: enriched document-level artifacts
- 04_docs_sim: documents with similarity metadata
- 05_chunks: chunked outputs
- 06_eval_outputs: evaluation and benchmark outputs
- 07_delivery: final datasets for consumer systems
